# GitHub Achievement Practice

用于练习 GitHub Issue、Pull Request 与相关成就流程的临时仓库。

[English](./README.en.md)

## 功能

`practice-1.txt` 与 `practice-2.txt` 是练习文件。

## 使用

围绕练习文件创建 Issue、修改文件并提交 Pull Request，用于熟悉 GitHub 的协作流程。

## 说明

仓库只保存练习文件，验证完成后可删除。
