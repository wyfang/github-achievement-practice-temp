# GitHub Achievement Practice

A temporary repository for practicing GitHub Issues, Pull Requests, and related achievement workflows.

[简体中文](./README.md)

## Features

`practice-1.txt` and `practice-2.txt` are practice files.

## Usage

Create an issue about a practice file, edit the file, and open a pull request to learn GitHub's collaboration workflow.

## Notes

The repository only contains practice material and can be deleted after the exercise is complete.
